# 📚 Book Finder — Aganitha Take-Home Challenge

### Candidate ID: Naukri1025

A simple React + Tailwind app for searching books by title using the **Open Library Search API**.

---

## 🚀 Features
- Search by book title (live debounce)
- Book cover, author, and publish year
- Click to open full details on Open Library
- Responsive UI (mobile & desktop)
- Error handling for no results / network issues
- Clean and minimal UX

---

## 🛠️ Tech Stack
- React + Vite
- Open Library API: `https://openlibrary.org/search.json?title={bookTitle}`

---

```bash
npm install
npm run dev
